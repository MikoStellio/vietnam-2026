## Key decisions / conventions used
- **Format:** HTML slide deck chosen over markdown because it's presentable offline on phones and printable to PDF; each `<section class="slide">` is a page-break unit when printing.
- **Restaurant strategy:** deliberately avoided naming many specific shops (except well-known anchors like Bún Chả Hàng Mành, Café Giang) — instead gave *selection rules* (busy + local customers + hot-cooked + Vietnamese menu) so the family can adapt on the ground and avoid outdated/wrong shop names.
- **Safety framing:** every meal recommendation ties back to the 7 safety rules; raw/ice items explicitly flagged.
- **Itinerary changes suggested** (not applied to the plan file): drop Moana Cafe if tired; shorten Day 4 Tam Coc exploration; keep Day 5 evening light before flight day.
